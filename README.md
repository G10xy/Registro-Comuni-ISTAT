# Registro Comuni ISTAT 🇮🇹

Un'applicazione robusta sviluppata in Java e Spring Boot per l'analisi, l'elaborazione e la gestione dei metadati completi associati ai registri comunali (Comuni) dell'ISTAT.

## 🚀 Informazioni sul Progetto
Questo progetto gestisce l'elenco completo di tutti i comuni italiani insieme ai relativi metadati, offrendo una struttura dati affidabile per scopi di mappatura amministrativa e geografica.

## 🛠️ Tecnologie Utilizzate
* Java / Spring Boot
* Maven
* Docker

## ⚙️ Guida all'Uso

### Prerequisiti
* Java JDK installato
* Maven

### Installazione ed Esecuzione
1. Clona il repository:
   ```bash
   git clone [https://github.com/fernandoripol/Registro-Comuni-ISTAT.git](https://github.com/fernandoripol/Registro-Comuni-ISTAT.git)


   Accedi alla cartella del progetto:
Bash

cd Registro-Comuni-ISTAT

Avvia l'applicazione tramite Maven:
Bash

./mvnw spring-boot:run
